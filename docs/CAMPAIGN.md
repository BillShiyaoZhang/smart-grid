# 电流的足迹：全球电力史教学战役

从欢迎页选择「历史战役」，按顺序进入十五个独立情景。每关使用自己的预算、设施、科技与经营问题；通关解锁下一关，已经完成的章节可以重玩。序章可跳过，历史档案中的来源链接可以查阅背景。

任务单只突出当前阶段；「定位操作入口」打开实际工具或经营中心，「给我一个提示」逐层展开帮助。没有自动代建、免费补钱或点击「下一步」代替运行结果。建设和运营费用、现场队占用、储能损耗、远程执行复验均参与真实仿真。

普通稳定供电阶段需要连续两游戏小时达到98%，城市服务观察十二小时，风电阶段观察四小时。最终综合考核需要连续二十四小时供电率至少98%、实际可再生供电比例至少50%，且该窗口运营净收益非负。暂停、读取界面和刷新报价不会增加达标时间。

资金低于−20,000时经营失败。灾害和安全关由玩家点击「开始考核」后触发，关键负荷连续失供两游戏小时也会失败；可选择重试本关。进入考核前不会因为默认周期风暴或网络事件突然打断教学。

## 历史与模型

地点、年代和工程背景参考每关历史档案中的政府、博物馆、实验室、电网企业或运营商资料。任务、地图、资金、容量、工期、人才名额和生态参数均经过教学改编，不代表历史工程实测值。

劳芬使用预置水力电源；田纳西关呈现区域电气化，不复现诺里斯水库调度。哥特兰将大陆电网作为固定购电的地图外接口，仍需经过本地真实线路交付；不模拟双端直流海缆。英国市场使用本游戏统一交易规则；南澳不模拟频率辅助服务。战役不收录假想聚变等未来技术。

场景的街区、河流与山地使用现有低多边形资产。地形区域同时约束水电、抽蓄选址；历史早期关闭现代车辆和道路标线。未知故障与设施读数继续遵守巡检和可信遥测规则，任务提示不会提前泄漏精确故障。

## 存档与自由运营

战役运行存档、自动存档和章节解锁进度分别保存。重玩旧章不会清空已经解锁的后续章节；切入战役前备份当前沙盘，返回沙盘可恢复该进度。自由运营、爱迪生历史沙盘及原四项运营委托仍保留。

schema 6增加当前战役章节、阶段、计时、事件和必要操作记录，兼容schema 1—5旧存档。旧档按非战役读取；无效战役数据整份拒绝，不替换当前游戏。异步操作以实际执行回执判定，排队成功并不等于操作已经生效。
