# 电力市场：从供电到经营

交易中心把电网建设、电价、储能和经营账本放在同一个循环中。报价、需求反应和合约都是确定性的游戏模型，所有资金均为游戏内经营数值，不涉及真实市场或真实资金。

## 一次完整操作

1. 先把中央变电站与东侧工业园区连接，建立稳定的售电收入。
2. 按 **M** 或点击顶部「电力市场」，观察未来 24 小时现货与零售电价曲线。
3. 点击「建造市场联络站」，返回地图放置设施，再用接线工具连接到本地电网。联络站基础价格 **¥32,000**，双向容量 **14 MW**。断线、检修和风暴会影响实际交付。
4. 返回交易中心，在「购售电策略」选择策略和价格阈值，点击应用。
5. 在「零售电价」和「储能与锁价合约」设定方案，分别点击对应应用按钮。
6. 返回电网运行，或直接点击交易中心的「推进 1 小时」，检查实际潮流、用户满意度、资金与「运营结算账本」。

打开交易中心会暂停自动时间。**编辑字段只形成草案；点击应用才生效；推进时间才结算。** 切换页面、刷新预测与重复打开窗口不会买卖电、改变电量或重复收费。普通刷新保留未应用的草稿，重新打开页面时会同步当前生效配置。按 M 或 Esc 返回电网。

电池检查器可直接打开储能页，联络站检查器也有市场入口。市场配置和账本会随手动或自动存档保存；重新开始会恢复默认策略并清空合约和账本。

## 购售电需要真实路径

| 策略 | 行为 |
| --- | --- |
| 离网运行 | 禁用外网电力交换 |
| 缺电保供 | 本地风光、燃气和电池优先，在买价阈值内补充剩余缺额 |
| 经济交易 | 在阈值内使用低价进口替代部分燃气，并允许富余风光、符合策略的储能及有正燃料利润的燃气余量外售 |

最高买价决定愿意接受的现货报价，最低外售价决定外售门槛；它们不是固定成交价。初始阈值分别为 **¥120/MWh** 和 **¥90/MWh**。当前外售结算价为现货买价的 **72%**，因此即时倒手不能产生无成本收益。同一电气岛不会在同一步同时进口和出口。

联络站位于电网图中，进口和出口都会改变支路潮流。联络站容量不是线路容量：即使外网还有余量，下游支路仍可能过载跳闸。离开用户所在连通岛的联络站不能隔空供电；增加备用路径、线路增容和检修仍然重要。

## 电价与用户

默认统一电价为 **¥145/MWh**。峰谷预设为谷价 **¥85**、平价 **¥145**、峰价 **¥220**；也可自行调整：

| 时段 | 时间 |
| --- | --- |
| 谷 | 23:00–次日 07:00 |
| 平 | 07:00–17:00，21:00–23:00 |
| 峰 | 17:00–21:00 |

统一电价使用平价覆盖全天。高价会压低住宅与工业用电需求；医院保持关键负荷，不参与该价格反应，且医疗供电零售结算价最高为 **¥145/MWh**。持续高价与停电会降低满意度，满意度过低进一步影响需求。提高单价有时会增加短期收入，也可能减少售电量并损害后续经营。

当前住宅与工业的价格弹性系数分别为 0.22 和 0.30，价格反应倍率限制在 0.55–1.15。满意度低于 60 时还会叠加用户留存倍率 `0.25 + 0.75 × 满意度 / 60`，最低只保留四分之一的普通用户需求；医院需求不受该留存变化影响。满意度在电价不高于 ¥145 且供电至少 98% 时缓慢恢复，高价和失供则持续降低满意度。

现货价格由时段、游戏日和天气决定，夜间通常较低、傍晚高峰较高，风暴会加价。24 小时曲线是基于当前天气的参考预测，不承诺未来实际成交价格；当前风暴不会被简单外推为整整一天。

## 储能与锁价

「保供备用」让电池主要吸收本地富余风光并在供电不足时放电。「峰谷套利」额外使用充电买价、放电价和最低备用 SOC，尝试在低价时购电充能、在高价时支撑负荷或外售。默认充电阈值 **¥60/MWh**、放电阈值 **¥150/MWh**、备用比例 **20%**。充电价必须低于放电价，且实际购电仍受交易策略与最高买价约束。

电池受 MW 功率、MWh 能量及充放电损耗共同限制。套利不会免费创造能量，保留较多备用电量也会减少可用于套利的电量。

锁价合约界面提供 **12 游戏小时**固定功率购电。签订前，页面显示功率、单价、期限及总承诺额。它是按约定功率持续付费的合约：**用不完、线路故障或关闭外网交换时仍需付款**。它可以对冲后续涨价，也可能让玩家错过低价。合约功率受可用联络站容量限制，每次只允许一份有效合约；有效期内不可取消或重复签订。

签约本身不提前扣除全部费用，费用在随后时间推进中计入账本。只有实际可达的电网路径才能交付，超出合约交付的购电按现货规则处理。

## 读懂账本

账本按游戏日归集运营现金流，保留最近 30 个游戏日，界面展示最近若干日。各项都来自时间推进中的实际仿真：

**净收益 = 零售收入 + 外售收入 − 现货购电 − 锁价合约 − 燃料 − 运维 − 失供补偿。**

其中零售收入按实际供给用户的 MWh 与当时零售价计算，医院适用上述监管上限；失供补偿为 **¥60/MWh**。购售电 MWh 列显示实际交付能量，不是联络站的额定 MW。燃气燃料成本为 **¥68/MWh**，经济交易仅在外售价高于燃料成本且同岛没有进口时使用闲置燃气余量外售，并继续尊重玩家设置的出力上限。

建造、研究、维护派单与委托奖励不属于运营结算账本，单独保留在调度日志中。因此，只有在没有这些额外支出或奖励时，某段时间的总资金变化才应恰好等于账本净收益变化。

## 实现与验证

`scripts/sim/power_market.gd` 管理报价、电价、用户满意度、合约与账本；`grid_sim.gd` 在各连通岛内统一处理实际电力交换。`scripts/ui/market_panel.gd` 提交配置命令并显示结果，`market_chart.gd` 只绘制预测。

存档当前为 **schema 6**，包含市场配置、合约剩余时间、满意度、账本、数字网络及独立战役阶段。schema 2/3/4/5 的市场配置保持兼容；加载 schema 1 时补充默认市场状态。市场能力属于当前实现，其他底层电力近似仍见 [架构说明](ARCHITECTURE.md)。

历史战役早期使用固定零售计费，不开放现代现货与合约。哥特兰关的外网供电按固定价格真实结算，接口与本地线路继续约束交付；进入英国市场关后才学习玩家可配置的交易规则。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s tests/test_market_game.gd --log-file /tmp/tidal-market-game-test.log
```

市场核心测试覆盖报价、电价与需求、物理贸易、储能、合约、结算和存档。界面集成测试通过真实按钮回调验证草案、M/Esc、模态暂停、联络站建设接线、进口和外售、断线、合约承诺、账本与资金一致，以及预测刷新没有资金或能量副作用。

混合电源按逐机组实际边际成本参与经济交易：免费水电优先于付费进口，煤电、燃气、联合循环和早期直流机组使用各自燃料成本；外售不会因统一燃气阈值而调起亏本机组。最低承诺负荷、爬坡、厂用电、线路容量及储能策略继续约束实际交付。储能的可再生来源会随存档保存，长期清洁目标使用实际供电来源比例。
