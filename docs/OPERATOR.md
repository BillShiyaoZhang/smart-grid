# 调度员操作指南

潮汐电网的经营判断依赖三件事：电网实际能交付多少、当前证据足够支持什么判断，以及操作何时真正生效。复杂电网仍由玩家规划；界面帮助定位证据、比较取舍与核对结果。

## 从缺电到处置

右侧只使用一个工作区，在「对象」「诊断」「关注」「队列」之间切换。

| 页面 | 用途 |
| --- | --- |
| 对象 | 选中设施或线路，查看已知状态、额定参数和适用操作；高级控制按需展开。 |
| 诊断 | 点击供电数字或告警入口，查看当前缺额、已知告警、证据来源及下一步；可直接定位目标。 |
| 关注 | 使用 Ctrl+F 检索设施或城市；设施支持名称、类型、编号、可信度、异常及类别筛选，星标可固定关注。 |
| 队列 | 查看在途远程指令、现场作业及本次会话近期执行回执，再定位相关对象。 |

一个常见流程是：发现已供小于需求 → 打开诊断 → 区分未接线、已核实故障、启动/配套约束、可见线路瓶颈或待核实状态 → 定位对象 → 选择接线、调整、巡检、维修或备用方案 → 等待回执及真实供电变化。

诊断列出的是可知证据与可执行下一步，并不保证一次列出所有根因。有额定容量不等于当前可用，有可用电源也不等于线路能交付。信息不足时，应先建立可信遥测或取得现场记录，避免直接把缺额解释成缺少电厂。

右上菜单可在「镜头：工作区」与「镜头：全图」之间切换。检索、告警、拓扑节点及任务定位会把相关对象带入视野并选中；远距地图用屏幕上的设施聚合标记辅助辨认。

## 建造、接线与拆除

- 选择建设分类与设施，悬停地图查看「可建 / 不可建」、造价和具体原因。占用、边界、选址、科技及预算与实际提交使用同一套校验；预览不会扣钱、推进时间或生成设施。
- 水电和抽蓄的公开选址范围会直接叠在地图上。范围内仍需满足空地与预算等条件；范围表示允许选址，不是发电收益预测。
- 电缆和通信工具选择起点后显示随光标变化的候选线，悬停目标检查端点、费用与合法性。光纤/无线详细报价也可在数字中心查看。连接失败会保留起点，便于换一个终点重试。
- 新设施建成后仍需接网。数字设施既需要电力连接，也可能需要独立通信；建设电缆不会自动建成光纤。
- 选择工具会自动切到对应的电力或通信专题层；返回选择工具时恢复先前图层。右键取消当前操作，Esc 优先关闭当前浮层或中心，再取消工具。
- 拆除先显示退款及将移除的电力线路、通信链路，确认后执行。取消保留现状。拆除可能使关联负荷失供或终止对象的在途操作；当前版本没有完整的经营历史撤销。

费用与合法性预览不承诺施工后的精确潮流、收益或供电率。提交后应重新观察供需、线路与现金流。

## 草案、提交与真实执行

市场、数字电网及科技规划中心会暂停自动时间；「推进 1 小时」或「推进 15 分钟」会真实结算供电、费用、研发、队列与城市变化。主状态栏区分运行倍率、手动暂停及规划暂停，并显示返回后恢复的状态。地图上的轻面板会继续走时。

**草案**是尚未提交的编辑。市场的交易、电价、储能区分别保留草案，设施运行按每个设施分别保留，数字中心保留安全策略草案。普通刷新、切页、关闭重开或提交其他配置不会把它们清空。页面显示草案与生效值差异，「重置本区草案 / 重置此设施草案」只恢复当前区或对象。

**已排队**表示操作已受理。设施出力、启停及策略设置需要远程指令或现场队执行，设备不会因按钮点击立即采用新值。现场方式需要费用、队伍及约 21 游戏分钟；远程方式依赖研究、可信路径和新鲜遥测，到达时再次验证。新编辑不会自动替换在途设置，仍需另行提交。

**已执行 / 已拒绝**来自实际完成回执。成功后核对生效值；拒绝时保留原生效设置，查看失败原因并恢复条件后重试。队列为空只能说明没有等待项目，不能据此推断某项设置已经成功。地图对象、右侧队列及数字中心均可查看相关结果。

读取、重新开局或切换进度会清理本次会话的草案、关注列表、趋势图历史与近期回执；存在待处理配置时先确认，取消后可继续编辑。实际已排队命令保存在游戏存档中，读档后按存档内的剩余时间继续；近期界面回执不作为永久运营账本保存。个人显示与快捷键设置独立保留。

## 比较、图表与信息边界

科技规划的「设施与精细调度 → 建造目录」支持最多三项设施对比：造价、额定 MW、储能 MWh、额定时长、往返效率、热机启动与最低负荷，以及设施自身约束。对比额定参数后仍应检查实际选址、配套和网络交付能力。狭窄窗口可以纵向滚动，市场账本宽表另有横向滚动。

统计供需图的横轴是当前情景的实际游戏日期与时刻，保留本次会话最近 24 游戏小时的观测快照；供给与需求为实线，已供电为白色虚线，红色区域表示未满足需求。暂停刷新只更新当前快照，不能制造新的时间跨度。长时间手动推进之间没有逐分钟记录时，图表不补造中间采样；读取或切换情景后重新积累历史。市场的未来 24 小时报价图是参考报价，不是实际成交账本或精确的负荷、天气预测。

| 信息 | 如何解读 |
| --- | --- |
| 额定容量、设施身份、已建连接、公开选址 | 可直接用于规划，不代表实时运行读数。 |
| 可信遥测 / 现场核实 | 可查看对应的已知功率、开关和已定位故障，注意记录年龄。 |
| 过时、可疑或未观测 | 保留未知标记或明确的旧记录，不绘制成确定的实时故障、零功率或正常状态。 |
| 线路虚线 | 在电力视图可能表示未知、断开或已知故障，需结合标记、图例与检查器；通信视图的线型用于区分介质。 |
| 城市供电反馈、全局供需、气象预报 | 属于公开运营反馈，不提供未知线路的精确故障位置。 |

电力与通信拓扑分开显示，选中线突出端点，可信流向用箭头辅助读取；故障、未知和异常也使用形状或文字提示。自动化、地图图层、搜索、诊断与任务提示均不能替代可信观测。战役的「定位操作入口」聚焦当前任务对象；未知物理故障先定位受影响用户，取得可靠证据后再指向故障线。

## 显示设置与键盘

右上菜单打开「操作与显示设置」，可立即切换 100%、125%、150% 的界面与字号比例、高对比界面和减少天气、电流等装饰动效。设置独立保存，不改变电网仿真、战役解锁或经营难度。窗口最低 1280 × 720；放大字号时中心采用单一纵向滚动。

工具、视角平移/旋转、暂停、经营中心、手册和存读档默认键可重绑。点击按键后输入新键；若已有其他操作使用该键，交换两个绑定。Esc 保留用于取消捕获、关闭或返回；Ctrl+F 和鼠标操作保持固定。Tab / Shift+Tab 可在当前模态窗口内导航，读数输入不会触发背景建设操作。

默认按键表见 [README](../README.md#操作)，游戏手册显示当前绑定。沙盘欢迎页的开始运营入口提供可跳过的首次接网引导；历史战役每步提供「概念线索 → 对象与入口 → 明确操作」三级提示，不会自动代建或免费完成考核。

当前封面与全部 29 个设施图标从实机使用的同一组低多边形模型渲染，便于把目录、封面和地图中的设备对应起来。设置及视觉可读性已通过自动测试与实机截图检查；真实玩家的理解、效率和偏好仍需按 [验证记录](VALIDATION.md) 中的观察任务验证。
