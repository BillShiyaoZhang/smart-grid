# 提前规划、资产运维与用户侧能源

本轮将起始报告中的经营、工程和用户侧方向接入同一套仿真。新系统使用现有设施和工作台，不要求重开现有沙盘。

## 入口与投运顺序

| 入口 | 新内容 | 前置条件 |
| --- | --- | --- |
| 发展 **T** → **预测与推演** | 24小时供需、风光、储能、备用缺口与三方案比较 | 可直接参考；观测不足会降低可信度 |
| 运维 **N** → **资产与街区** | 设备寿命、现场队、输配电、街区能源与微电网 | 研究 **区域负荷规划** 后出现，分别点击投运 |
| 运维 → 街区能源 | 智能电表、用户侧光储、充电、需求响应 | 区域负荷规划及 **SCADA调度接口**，再投运用户侧协调 |
| 经营 **M** → **长期经营与复盘** | 停电与资金记录、项目、贷款、日前购电、备用、政策及灾害 | 记录可查看；长期经营操作需区域负荷规划并投运 |

资产风险、输配电、用户侧协调和长期经营分别投运。经营路线须先完成接网、昼夜供需和清洁盈利，再投运高级体系。投运后规则持续参与该局运行，保存后保留。历史教学关卡使用原有情景规则，不启用这些自由配置的扩展。

推荐先稳定现有供电，建立可信观测，再研究区域负荷规划。先用预测看清晚高峰，随后逐项投运新规则并观察结果。

## 预测与方案推演

刷新预测可查看未来24小时的需求范围、风光、净负荷、储能电量、外购需求、备用余量及线路负载。MW表示当前供需，MWh表示可继续使用的电量。

选择一台机组的出力计划、储能保留比例和是否允许外购，比较当前方案、所选方案、再退出一条线路或一座设施三种情况。结果列出失供电量、资金变化、最大负载和最低电压。

推演运行在独立副本中。刷新与比较不会推进真实游戏、消耗电量、结算资金或完成任务。计划参数只用于比较，真正调整运行仍需回到对应设施提交设置。

预测依据玩家已有信息，使用15分钟参考步长，在隔离后台任务中计算，界面仍可响应。未知设备按列出的健康、启停和储能假设估算；未知电表按声明的用电需求和假设电量估算。它不会预知精确的随机故障或未发现的网络事件。图中的范围是规划情景区间，不是经过统计校准的概率置信区间。计算期间若真实运行状态或会话发生变化，旧结果会被丢弃。

**练习：**中午比较积极放电与保留20%电量，观察傍晚外购、缺口和线路负载。对慢启停机组，先查看它能否在缺口出现前达到所需出力。

## 设备寿命、检修与现场队

投运资产风险管理后，年龄、健康、过载压力和恶劣天气共同影响故障风险。推迟检修可能暂时省钱，也会增加停机风险。隐藏故障仍需遥测或巡检核实。

| 处置 | 作用 | 主要取舍 |
| --- | --- | --- |
| 现场巡检 | 核实状态，不直接修复 | 花费队伍与出行时间，换取可信信息 |
| 计划保养 | 对可运行设备恢复部分健康 | 短时停运，不能代替故障大修 |
| 部件大修 | 修复故障并恢复较多健康 | 更长停运，消耗关键备件 |
| 设备更换 | 更新设备状态，恢复储能健康 | 更高费用和停运时间，消耗更多备件 |

报价包含出行和作业时间。两支现场队同时承担原有抢修、巡检、现场设置、新检修和微电网现场切换。待出发任务可调整优先级，或取消并退回费用与备件；出发后的任务要等实际完成。接单不等于设备已恢复。

关键备件每件¥700，库存上限30件。不要等关键设备故障后才发现库存不足。

集中式与社区储能记录累计吞吐和SOH。循环与日历老化降低有效MWh容量，频繁套利会带来后续维护成本。实际充放电只在推进时间时更新，查看界面不会增加老化。用户侧小储能使用独立街区模型，目前未另设SOH。

## 输配电、供电质量与保护

投运后线路分为**配电**和**输电**两级，不同等级只能在变电站衔接。等级改造按长度收费；提高电压等级降低长距离压降和损耗，不直接增加线路热容量。线路增容仍使用原来的增容操作。

变电站有独立的额定MW容量，可以按新增容量付费扩容。即使线路都很宽裕，站内容量仍可能限制下游供电。负荷附近的电源与储能可减少远距离运输；少量本地电源不能掩盖远端变电站的实际瓶颈。

长而重载的配电线路损耗更大，电压偏差也更大。损耗由实际发电或外购电支付；供电质量约束可能减少可交付负荷。比较输电改造、就地储能、备用路线和变电扩容，看它们分别改善哪一种限制。

保护延时倍率影响允许的过载持续时间。分区名称帮助区分馈线，持续变电超限会对下级重载支路分段处理。支路故障演练会**真实损坏并隔离**所选线路，需准备备用路径与抢修。通信中断不影响本地保护；自动转供仍需可信可控的健康路径。

**模型边界：**容量采用实际出力节点的供电路径近似，并补充初步DC潮流的下游变电通过功率检查；电压采用有功压降近似，损耗按电流平方效应的简化形式迭代结算。它保留长距离、重载、反送及就地供电的战略后果，没有完整AC、三相不平衡、无功求解或精细继电保护整定，不是电网工程设计工具。

## 街区电表、光伏、储能与充电

选择住宅、工业或医院街区，先安装智能电表，再配置屋顶光伏、用户侧储能和充电设施。新安装与新增容量分别付费。每个街区采用聚合模型，不模拟逐户电表或逐辆汽车。

屋顶光伏先满足本地用电，再给用户侧储能充电，剩余功率才进入公共电网。夜间用户侧储能先服务本地需求。公共电费按电表后的净用电量结算，因此自发自用会降低公共电网售电收入。用户侧储能目前只吸收本地光伏富余电量，不能直接采用集中式储能的外网套利策略。

充电同时设置MW功率、待完成MWh和每日完成时刻。普通充电接入即充；获得用户授权且通信可信时，智能充电可在电量来得及完成的前提下避开日间、转向夜间，临近期限会恢复充电。失联回退本地即充，到期未完成的电量产生补偿。

街区电量、充电余额、待回补电量与疲劳需要新鲜可信电表读数。没有读数时显示未知或过时，不能将空白当作零。

## 需求响应：削减与移峰

新街区响应要求电表、用户授权、参与率、可信通信和新鲜观测。可选择5%—50%的比例，持续0.25—4游戏小时。效果还取决于参与率与疲劳，补偿按实际执行电量计费。

- **削减**：减少该时段用电，按较高单价补偿用户。
- **移峰**：暂时推迟用电，增加待回补MWh；结束后逐步回补，不会永久删除需求。

反复使用增加疲劳并减少后续能力，休息后逐渐恢复。失联时不能继续指挥新响应，已推迟的电量仍需归还。原有¥1,000、两小时削减20%的基础响应保留供既有玩法和教学使用；街区合同提供额外的精细协调入口。

## 微电网与分阶段恢复

在微电网页多选成员与关键负荷并命名。一个设施只能属于一个微电网。离网时找出跨越边界的线路，安排远程或现场切换；“已排队”不等于边界已经断开。

现场切换使用一支队伍、收取¥350并等待作业。远程切换要求全部边界可被可信控制，到达时再次验证；边界或通信变化会拒绝整次切换。

边界断开后，先检查本地启动电源或有电量的构网储能。缺乏支撑时，光伏不能独自点亮整个岛；支撑就绪后先恢复关键负荷，半游戏小时后再开放普通负荷。能量和容量仍由调度决定，阶段开放不保证电量充足。

构网用户侧储能在已形成的岛中可将剩余功率供给其他成员，实际外送才扣除电量。重联只操作本次离网记录的健康边界线路。这里采用聚合启动与恢复阶段，没有频率动态、同步相角或详细逆变器控制。

## 工程、融资与电力承诺

长期经营投运后，大型设施和长距离线路按工期建设，报价包含场地或走廊准备。付款后预留位置，到工期完成才投运。小设施保持快速建造。项目页可查看进度、受阻原因或取消；取消在建项目退回未施工部分费用的80%，已完成的准备和施工费用不退。

贷款本金立即进入现金，利息随时间结算；默认日利率0.5%，逾期翻倍，可提前还本，总授信上限¥1,000,000。贷款不是营业收入，偿还本金也不是发电成本，统一现金记录可分别核对。

日前购电用逗号分隔的MW序列提交1—24个逐小时承诺，从下一整小时开始。已有承诺不可覆盖或取消。每小时按约定功率和锁价付费，断线、离网或用不完仍需付款；超出的实际购电按现货结算，实际与承诺的偏差再按现货价格的5%收履约费。这是简化实物承诺，不是允许未用电量无限套利的金融合约。

备用由已启动机组或有足够电量的储能提供。承诺功率从日常可用功率中保留，按实际履约能力获得收入，不足产生违约费用，不能同时把同一功率卖成能量和备用。

区域市场可采用原有参考价格，或由三类聚合外部供应报价按需求统一出清。报价系数用于设定情景；没有完整订单簿、节点电价或战略竞争者AI。

## 政策、灾害与经营结果

长期经营可分别设置碳价、可再生生产补贴、零售电价上限、供电目标和失供附加罚款。热浪同时增加区域负荷并降低部分机组能力；洪水影响同一范围的设备；燃料中断降低燃料机组可用出力。它们是可配置的经营演练情景，燃料中断暂不追踪逐种燃料库存。

可靠、可负担、清洁、韧性和财务目标均要求连续达标24游戏小时，条件中断重新计时。五个维度分别展示，不合成一个任意总分。

停电复盘记录负荷节点的起止、时长、失供MWh、关键负荷影响和恢复曲线。原因使用公开停电报告和已核实线路证据，不提前公开未知故障。记录按聚合负荷节点统计，不声称是按真实客户数计算的SAIDI/SAIFI。

统一现金记录包含运营、建设、研究、维修、补偿、奖励、项目、融资和政策。旧档载入以当前现金建立期初余额，不会捏造过去没有保存的明细。为限制存档体积，详细资金与停电曲线采用有界保留。
