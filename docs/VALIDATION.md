# 验证记录

## 八项跨系统联动修复验证（2026-10-29）

在 Windows、Godot 4.7.2、Compatibility / OpenGL、NVIDIA RTX 3070 Ti 完成验证。17 套测试共 **1,225 项检查，0 失败**，其中新增五套跨系统测试共 252 项，原有测试同时补充队列与回执断言。

| 修复项 | 实现与关键验收 |
| --- | --- |
| 1. 经济调度 | 逐机组真实边际成本；水电优先、煤电与现货比较、高成本机组不亏本外售；混合电源与节点功率守恒。 |
| 2. 热机约束 | 额定最低负荷、有限配套分配、真实辅机优先供电、运行失供安全停机与有电冷启动；重算不重复扣减储能。 |
| 3. 城市归属 | 人工建设客户加入最近城市，人口改变需求，失电影响服务率；新旧存档保持双向归属。 |
| 4. 设施控制与观测 | 远程到达时复验，失联拒绝；现场费用/队伍/21分钟延迟；地图、检查器与规划共同隐藏未知读数，待执行草案保留。 |
| 5. 升级与检修 | 分类型有效升级，无能力收益的购买被拒绝；变电站检修隔离与恢复，冷却升级增加真实配额。 |
| 6. 储能来源 | 光储夜间可再生供电继续累积清洁目标；混合来源按比例扣减，效率损耗、外网未知来源、零时间查询与保存恢复正确。 |
| 7. 数字投运边界 | 历史数字化前无免费网关/光纤/UPS/入侵；自然事件遵守拓扑，演练显式注入；根角色可重建并持久化。 |
| 8. 资产退款 | 免费市政种子和自动扩张不能产生建造退款；玩家投资及付费升级按35%回收；拆迁安置需求、重建偿还、伪造旧档字段规范化。 |

测试计数：主仿真182、主界面63、市场140、市场界面67、数字120、数字界面93、代际58、区域32、沙盘76、规划51、求解器20、HUD71、混合调度59、热机联动52、城市资产82、数字边界47、设施界面12。

存档升级为schema5，兼容读取schema1–4。新增字段包括设施命令/观测、设备投运角色、可再生储能、投资退款与拆迁安置需求。未知旧储能来源保守不计可再生；旧版本自带的未来字段按规范默认值重建；非法schema5数据整体拒绝而不替换当前游戏。未进行发行导出或长时性能压力测试。
