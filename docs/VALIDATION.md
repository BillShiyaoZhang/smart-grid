# 验证记录

在本机 Godot 4.7.2（Apple M4 Pro，Compatibility / OpenGL）运行验证。

- 仿真测试：182 项检查，0 失败。包含功率/储能守恒、环网分流、开关、过载保护、维修并发、医院优先、遥测、自愈、自然风暴预告、停电补偿、确定性与存档往返。
- 主场景集成：63 项检查，0 失败。包含真实按钮回调与地图工具、3D 屋顶和塔身光线拾取、现场开关排队、巡检再维修、通关/继续/重开、昼夜和雨幕、需求响应、保存恢复与模型同步。
- 市场仿真：140 项检查，0 失败。包含双向交易与线路约束、燃气外售成本、价格边界、用户留存与医院电价上限、储能套利守恒、按约收费、跨日账本和新旧存档校验。
- 数字电网仿真：120 项检查，0 失败。包含独立通信、UPS与冗余根、缓存质量、在途指令复验、巡检及精准维修、事件与防护、离线本地保护、费用、旧存档迁移和非法数据整体拒绝。
- 市场界面集成：59 项检查，0 失败。包含 M/Esc、所有市场入口、模态暂停、草案保留、真实电价作用、联络站建设与接线、实际进口和外售、断线阻止交付、储能策略、合约承诺与禁重签、推进一小时、账本现金一致、预测刷新无副作用，以及载入和重开。
- 数字界面集成：87 项检查，0 失败。包含 N/Esc、暂停与十五分钟推进、独立通信布线不供电、UPS耗尽、可信遥测、远程排队/失联拒绝、现场恢复、未知故障在地图与检查器中隐藏、过时记录、风暴日志不泄漏、巡检定位、DoS/欺骗/传播路径修补、安全策略阻挡、队列存档与旧 schema 迁移。
- 代际技术：58 项检查，0 失败。包含研发前置/付款/时间、六代目录、真实选址、热机启动和降载、核能冷态辅助供电、冷却和人才名额、生态费用、研究控制、通信降级、保护时机及严格存档校验。
- 城市模型：32 项检查，0 失败。包含八城接管、玩家用地保护、真实未供电负荷、增长/衰落/空间扩张、农业与港口负荷差异、产业转向、扩张上限、人口持久化及查询无副作用。
- 沙盘联动：70 项检查，0 失败。通过完整潮流和经济验证基荷给抽蓄充电、不同效率、弃电与沉没燃料、碳排、冷态核能不能黑启动、辅助设施耗电、岗位不可重复、停机爬坡、逐设施备用、电力与通信停用、可信软件削峰及失联回退、历史解锁、完整区域存档/异常拒绝、持续目标计时。
- 规划界面：38 项检查，0 失败。包含真实模态、研究目录、草案保留、显式配置、地图建设、区域激活/定位、全部 16 种新模型、历史切换、隔离备份恢复、科技门槛和地形恢复。
- 潮流求解器：20 项检查，0 失败。包含带主元 LU、节点平衡残差、不同功率右端项复用、拓扑变化、奇异/非有限输入、不修改输入和 64 项缓存淘汰。
- 图形渲染：`tests/render_smoke.gd` 实际创建主场景，保存欢迎、经营、帮助、风暴、通关和夜间六种状态；人工检查 PNG 的文字、排版、地形、图标、灯光与故障标记。
- 市场渲染：`tests/render_market.gd` 保存购售电、零售电价、储能合约、结算账本及联络站五种实机状态，检查控件、报价、现金与图表排版。
- 数字电网渲染：`tests/render_digital.gd` 保存拓扑、操作、安全、事件、地图通信图层和观测检查器六种实机状态，检查中文、介质区别、可信状态与控制入口。
- 规划与区域渲染：`tests/render_planning.gd` 实际生成 `planning_technology.png`、`planning_storage.png`、`planning_region.png` 和 `planning_world.png`；检查科技前置、调度草案、城市地图、城市名称和河流/丘陵选址标记。

十一套逻辑与界面集成测试合计 **869 项检查，0 失败**。本轮区域性能抽查：80 个相连节点推进 0.5 游戏小时，由约 701ms 降至约 117ms；拓扑不变时复用 LU 分解，故障或接线改变矩阵后重新分解。求解器 30 次缓存的 80 节点计算约 4.5—5.6ms。完整模拟还包括通信、策略、费用与城市逻辑；该抽查不代表 512 节点全图长期压力测试。

复现命令见 README。无头运行在受限 macOS 沙箱中可能打印宿主 CA 证书访问警告；与游戏逻辑无关。图形运行及主场景测试没有 GDScript 错误。

本次未进行跨平台导出验证、长时性能压力测试或 OpenDSS 工程数值对照。项目以 Godot 源工程和本机启动脚本交付，未生成独立发行包。

市场验证范围为游戏模型中的现货与 12 小时固定功率锁价合约，不包含完整订单簿、竞价出清或真实资金交易。24 小时图表是价格参考，不包含实际需求预测或精确天气预测。数字网络是离线抽象模型，没有真实协议报文或外部攻击。当前存档 schema 为 4，兼容读取 schema 1/2/3；迁移与数值测试由对应核心测试覆盖。设备与人口参数为游戏模型，没有真实 AC 无功、水文、热力学和人口统计求解；聚变明确为假想未来路线。
