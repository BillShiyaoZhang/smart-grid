# 海湾微缩模型与图解经营

## 整体视听升级（2026-10-30）

已确认「精致实体微缩模型＋温暖钢琴与轻电子」方向，战役优先。六张新概念稿分别覆盖 [整体风格](design/visual-refresh-2026-10-30/01-style-board.png)、[主菜单](design/visual-refresh-2026-10-30/02-main-menu.png)、[战役目录](design/visual-refresh-2026-10-30/03-campaign-selection.png)、[设置](design/visual-refresh-2026-10-30/04-settings.png)、[日间经营](design/visual-refresh-2026-10-30/05-daytime-gameplay.png) 与 [夜间风暴](design/visual-refresh-2026-10-30/06-night-storm.png)。这些是风格参考，示例数值与建筑细节不是实机承诺；运行界面由Godot原生控件绘制，模型保持真实建造格、选址和点选规则。

- 标题页用无字海湾插画与原生导航，首次突出教学战役，有档时展示最新有效进度；暂停菜单保留场景、工具与原倍率。
- 深海蓝、奶油白、薄荷绿、琥珀关注及珊瑚红缺口保持语义一致，主按钮使用深字薄荷底，键盘焦点与降级后的悬停状态均明确。
- 全部29种设施共享倒角与哑光材质语汇，以屋顶、机电设备和结构轮廓区分；历史地貌保留年代装饰。设施图标、章节缩略图和图鉴从实际模型渲染。
- 模型工厂是唯一来源，静态几何按材质合并并缓存；模型提供 `bounds`、`pick_height`、`label_anchor`，供点选、标签与取景共用。保留 `Rotor` 和海水参数契约。
- 战役目录为时间线和选中章节详情；最低分辨率大字号时先显示章节列表，装饰大图让位于入口。五页设置采用可滚动内容和宽屏效果预览。
- 声音是独立表现层，音乐按标题、昼夜、战役与风暴交叉淡化，快进不加速。告警与设备声音只读取公开指标、可信观测和真实回执；读档先建立基线，密集回执按真实时间合并。

实际渲染的图标与模型见 [设施图鉴](../assets/models/art_catalogue.png)，音频来源与可复现命令见 [声音说明](../assets/audio/README.md)。

本轮以普通经营游戏玩家为对象，让供电问题、投资取舍和执行结果可以直接看见。建设、自动调度、物理电网和可信观测继续构成玩法，复杂系统随经营过程逐步开放。

## 行为要求

- 主界面回答是否缺电、缺口大小、现金与运营收益、当前主要问题。
- 地图、诊断卡、对象与操作队列共享目标，避免重复告警及跨页寻找设施。
- 发电区分额定、可用和实际输出；储能区分 MW、MWh、标称时长和当前可持续时间。
- 当前值、未提交草案、在途设置与真实回执分别表达。等待完成不得跳过中途拒绝、供电恶化或目标中断。
- 账本默认解释收入和成本，完整明细可以展开；报价参考与真实成交历史分开。
- 新经营流程循序开放接网、昼夜、清洁与成本、备用、跨城。自由沙盘和历史战役保留。
- 探索区域不立即承担新城市的供电责任。城市规划、建设与正式开通服务分别执行。
- 旧存档维持原有资产、策略、解锁和在途任务；不能准确映射的策略保留为旧版自定义。

## 数据边界

图表只使用公开运营反馈、额定参数、可信遥测和现场记录。未知不等于零，不得绘制未核实的故障、功率或健康；过时读数注明记录时间。历史随实际仿真时间采样，打开面板、悬停与刷新不产生历史或费用。操作前后变化属于观测对照，需要同时展示同期事件，不能冒充独立因果预测。

## 验收

覆盖 1280×720 至 1920×1080、100% / 125% / 150%、夜间风暴、高对比和减少动效。检查供需比例、未知读数、队列拒绝、共同尺度比较、账本守恒、策略生效与存档迁移，并以 Godot 实际渲染目视复核。自动测试之外，真人任务观察用于验证理解速度和操作效率，不以截图通过代替。
