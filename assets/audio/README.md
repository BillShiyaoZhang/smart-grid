# 潮汐电网原创声音

本目录全部音乐、音效与声景由 `tools/audio/build_audio.py` 中的原创旋律、编曲和确定性信号合成制作，没有使用外部录音、采样包、付费素材或音乐生成服务。温暖钢琴音色为加法合成的钢琴式音色，并非真实钢琴录音。

- 五首可循环配乐：标题、日间、夜间、历史战役、风暴，每首 2–3 分钟。
- 五个短乐句：章节开始、目标完成、通关、失败、恢复供电。
- 三个循环声景：海湾、夜间、风暴；独立雷声避免短循环重复。
- 七组轻量设施声：风机、热机、水力、变压器、数字设备、储能、城镇，覆盖全部 29 种设施。
- 操作、命令回执、存读档、告警等 21 个短音效。

`manifest.json` 记录每个文件的时长、采样率、峰值、循环接缝差值和 SHA-256。音乐和长声景为 44.1 kHz 立体声 OGG；短音效为 16-bit WAV。源信号保留约 2.85 dB 峰值余量，运行时再按声音类别混音。

复现命令（Python 需要 numpy，PATH 需要 ffmpeg）：

```powershell
python tools/audio/build_audio.py
```

音频属于表现层。`AudioDirector` 只接收公开运营快照、公开告警及已展示的回执；未知设备状态不会产生额外声音。读档先建立基线，避免重新播放历史告警和执行记录。音乐不随仿真倍率变速。
